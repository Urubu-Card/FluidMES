# Documentação do projeto unificado (legado)

Estes guias foram escritos quando backend e frontend viviam em um único repositório (`client/`, `server/`, `run_local.py`, `INICIAR.bat`).
O conteúdo funcional continua válido, mas caminhos como `server\manage.py`, `client/dist` ou `run_local.py` mudaram:
agora o backend e o frontend são projetos independentes. Consulte o `README.md` de cada um.
